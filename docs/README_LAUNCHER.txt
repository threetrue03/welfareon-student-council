복지온 Launcher 사용 방법 v1.0.9

1. build_launcher.bat 실행
- 런처 exe를 생성합니다.
- 콘솔에 빌드 단계가 표시됩니다.
- 상세 기록은 logs/build_launcher.log에 저장됩니다.

2. dist/복지온_Launcher.exe 실행
- 최초 실행 시 학과(부) 명과 관리자 계정을 생성합니다.
- 구글 시트 연동은 선택 사항입니다.

3. 중복 실행 방지
- 런처가 이미 실행 중이면 새 런처 창은 열리지 않습니다.

4. 오류 확인
- 일반 실행 로그: logs/log.txt
- 빌드 로그: logs/build_launcher.log
