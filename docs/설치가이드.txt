복지온 설치 가이드 v1.0.1

1. 배포 ZIP을 원하는 폴더에 압축 해제합니다.
2. build_launcher.bat을 실행해 Windows 실행 파일을 생성합니다.
3. dist 폴더의 복지온_Launcher.exe를 실행합니다.
4. 최초 실행 화면에서 학과(부) 명, 관리자 이름, 관리자 학번, 관리자 비밀번호를 입력합니다.
5. 프로그램 환경 설정 단계가 완료되면 다음 버튼을 눌러 구글 시트 연동 단계로 이동합니다.
6. 구글 시트 연동을 사용하지 않을 경우 건너뛰기를 누릅니다.
7. 프로그램 시작 버튼을 눌러 복지온을 실행합니다.

오류 발생 시
- logs/log.txt를 확인합니다.
- 환경 설정 중 오류가 발생하면 런처가 오류를 표시하고 초기화 실패 상태를 저장하지 않습니다.
