# WelfareON 업데이트 기록

## v1.0.12 - 2026-05-14

### 구글 시트 연동 UX
- `연결 테스트` 실행 중 로딩 애니메이션과 작업 안내 문구를 표시하도록 개선했습니다.
- `오늘 데이터 동기화` 실행 중 로딩 애니메이션과 작업 안내 문구를 표시하도록 개선했습니다.
- 처리 중 버튼을 비활성화해 중복 클릭과 중복 요청을 방지했습니다.

## v1.0.11 - 2026-05-14

### 런처 대시보드
- 의미가 불명확하게 보이던 빨간색 하단 바 문제를 제거했습니다.
- `브라우저로 열기` 버튼과 `주소창 없는 내부 창으로 실행됩니다.` 문구를 삭제했습니다.
- 시작/종료 버튼만 남겨 실행 흐름을 단순화했습니다.

### WebView 실행 관리
- WebView PID 저장/확인으로 내부 창 중복 실행을 차단했습니다.
- 프로그램 종료 시 WebView 내부 창과 서버 프로세스를 함께 정리하도록 수정했습니다.

### 구글 시트 연동
- 런처에서 저장한 구글 시트 설정을 웹사이트 설정 파일에도 함께 저장하도록 수정했습니다.
- 기존 런처 설정만 있는 경우 웹사이트에서 fallback으로 읽을 수 있도록 보강했습니다.

## v1.0.7 - 2026-05-14

### 통계 기능 제거
- 관리자 전용 `통계` 탭을 전면 삭제했습니다.
- 사이드바에서 `통계` 메뉴를 제거했습니다.
- 통계 페이지 URL, 뷰 함수, 템플릿, 전용 CSS를 제거했습니다.
- v1.0.6의 런처 환경 설정 화면 개선 사항은 유지했습니다.

## v1.0.6 - 2026-05-14

### 런처 환경 설정 화면
- 작업 출력 영역 높이를 확대하고 세로 스크롤바를 추가했습니다.
- 로그가 추가될 때 최신 출력 위치로 자동 이동하도록 유지했습니다.
- 진행률 숫자가 퍼센트 형식으로 명확히 보이도록 유지했습니다.
- 세부 작업 문구가 어색하게 잘리지 않도록 줄바꿈 폭과 영역 높이를 조정했습니다.
- 하단 버튼/푸터와 작업 출력 영역이 겹치지 않도록 런처 창 높이와 내부 배치를 조정했습니다.

### 빌드 파일
- build_launcher.bat 실행 시 빌드 로그가 콘솔에도 보이도록 개선했습니다.
- logs/build_launcher.log 저장은 유지했습니다.
- 혼동을 줄 수 있는 build_bauncher.bat 오타 대응 파일을 제거했습니다.

## v1.0.5 - 2026-05-14

### 런처 중복 실행 방지
- Windows Mutex 방식으로 런처 단일 실행 잠금을 추가했습니다.
- 이미 런처가 실행 중이면 새 런처 창을 띄우지 않고 안내창을 표시한 뒤 종료합니다.
- WebView 실행 모드는 중복 실행 잠금 대상에서 제외하여 프로그램 내부 창은 정상적으로 열리도록 처리했습니다.
- 기존 서버 실행 여부를 확인해 새 서버를 중복 실행하지 않는 흐름은 유지했습니다.

## v1.0.4 - 2026-05-14

### 런처/빌드 안정화
- `build_launcher.bat` 줄바꿈을 Windows CRLF 기준으로 정리해 `65001`, `UILD_LOG`, `rorlevel`처럼 명령이 깨지는 문제를 수정했습니다.
- 경로에 공백이 있어도 안전하게 실행되도록 `pushd`와 따옴표 처리 방식을 보강했습니다.
- `build_bauncher.bat` 오타 실행을 대비한 호환 배치 파일을 추가했습니다.

### 환경 설정 UX
- 환경 설정 화면의 왼쪽 진행 단계 박스를 제거했습니다.
- 현재 작업, 세부 작업, 진행률, 작업 출력을 한 화면에서 확인하도록 화면 구성을 변경했습니다.
- 프로그레스바를 왕복 애니메이션 방식에서 실제 퍼센트 기반 진행률로 변경했습니다.
- 가상환경 생성, 패키지 설치, DB migration, 관리자 계정 생성 출력이 작업 출력 영역에 표시되도록 보강했습니다.

### 조회 화면
- 아직 반납되지 않은 대여 기록의 반납 근무자가 `삭제됨`으로 표시되던 문제를 수정했습니다.
- 미반납 상태의 반납 근무자는 `-`로 표시하도록 변경했습니다.
- 학생으로 조회/물품으로 조회의 반납 예정일에 `D-day`, `D-n`, `D+n` 표기를 추가했습니다.

### 통계
- 관리자 전용 `통계` 탭을 추가했습니다.
- 오늘 대여/반납, 현재 대여 중, 현재 연체, 고장/분실 물품 요약 카드를 추가했습니다.
- 기간별 대여/반납 현황, 많이 대여된 물품 TOP 10, 카테고리별 대여 현황, 미반납/연체 목록, 근무자별 처리 요약을 추가했습니다.

## v1.0.3 - 2026-05-13

### 런처 안정화
- 프로그램 환경 설정 단계에 진행 프로그레스바를 추가했습니다.
- 환경 설정 완료 후 별도 자동 이동 없이 같은 화면에서 `다음` 버튼이 활성화되도록 변경했습니다.
- 최초 설정 시 기존 테스트 DB를 삭제하고 깨끗한 DB로 시작하도록 수정했습니다.
- 서버 중복 실행을 감지해 같은 DB를 사용하는 서버가 중복으로 뜨지 않도록 수정했습니다.
- 서버 PID 파일을 관리해 프로그램 종료 시 기존 서버를 정리하도록 보강했습니다.
- `build_launcher.bat` 실패 시 바로 꺼지지 않고 `logs/build_launcher.log`에 기록을 남기도록 수정했습니다.

### WebView/URL 처리
- WebView 내부에서 Shift+Enter, 새 창 열기, 외부 URL 이탈을 차단했습니다.
- 링크/폼의 target 속성을 자동 제거하도록 보강했습니다.

### 로그인/표시
- 로그인 로딩 표시가 버튼 클릭 전부터 보이는 문제를 수정했습니다.
- 학과(부) 명 뒤에 `학생회`가 중복 표시되는 문제를 수정했습니다.

## v1.0.2 - 2026-05-13

### 런처
- 종료 확인창에서 확인을 눌렀을 때 런처가 종료되지 않는 문제를 수정했습니다.
- 종료 시 실행 중인 프로그램을 정리하고 런처 프로세스를 확실히 종료하도록 보강했습니다.

### 물품 관리
- 물품별 위치를 입력하고 DB에 저장할 수 있는 `물품 위치` 필드를 추가했습니다.
- 물품 관리 표를 `물품명 | 물품 위치 | 유형 | 카테고리 | 수량/상태 | 관리` 구조로 변경했습니다.
- 물품 추가/수정 모달에 물품 위치 입력칸을 추가했습니다.
- 물품 검색에서 물품 위치도 함께 검색되도록 개선했습니다.

### 대여/반납
- 물품 대여/지급 화면의 번호 선택 영역에 물품 위치를 표시하도록 변경했습니다.
- 물품 반납 화면의 반납 번호 선택 영역에 물품 위치를 표시하도록 변경했습니다.

### DB 가져오기/배포
- 물품 DB 가져오기 양식을 `물품명 | 물품 위치 | 카테고리 | 물품 특성 | 전체 수량 | 현재수량` 구조로 변경했습니다.
- 물품 DB 양식 xlsx 파일을 새 구조에 맞게 갱신했습니다.
- 구글 시트 재고 현황에 물품 위치 열을 추가했습니다.

### 사이드바
- 사이드바를 닫았을 때 사용자 아이콘이 표시되지 않도록 수정했습니다.

## v1.0.1 - 2026-05-13

### 런처
- 관리자 학번 입력을 숫자만 허용하도록 변경했습니다.
- 현재 작업/로그 영역을 읽기 전용으로 변경했습니다.
- 프로그램 환경 설정 단계에서 현재 세부 작업을 표시하도록 개선했습니다.
- 환경 설정 완료 후 구글 시트 단계로 자동 이동하지 않고, 사용자가 `다음`을 눌러 이동하도록 변경했습니다.
- 로그 파일 보기 버튼을 추가했습니다.
- 환경 설정 오류 발생 시 사용자에게 알리고 초기화 실패 상태를 저장하지 않도록 수정했습니다.
- 창 닫기 버튼 클릭 시 확인 경고창을 표시하도록 변경했습니다.
- `단체명` 표현을 `학과(부) 명`으로 변경했습니다.
- 입력받은 학과(부) 명을 `<학과(부)명> 학생회` 형식으로 프로그램에 반영합니다.
- 구글 시트 연동을 건너뛰면 스프레드시트 ID와 서비스 계정 JSON 경로를 저장하지 않도록 수정했습니다.

### 웹 프로그램
- 로그인 처리 중 로딩 상태를 표시하도록 개선했습니다.
- 근무 종료 처리 중 로딩 상태를 표시하도록 개선했습니다.
- 근무 종료 버튼의 장식 이모티콘을 제거했습니다.
- 사용자 메뉴에 비밀번호 변경 기능을 추가했습니다.
- 비밀번호 변경 성공/실패 메시지를 토스트/메시지로 표시합니다.
- 로그인 화면과 사이드바 상단에 `<학과(부)명> 학생회`가 표시되도록 수정했습니다.

### 데이터/배포
- 학생 더미 데이터가 생성되지 않도록 초기 마이그레이션을 정리했습니다.
- 배포본에 실제 DB, 실제 관리자 CSV, 실제 구글 서비스 계정 JSON이 포함되지 않도록 정리했습니다.
- 업데이트 기록 문서를 추가했습니다.
