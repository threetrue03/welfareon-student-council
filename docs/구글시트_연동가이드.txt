구글 시트 연동가이드

1. 구글 스프레드시트를 생성합니다.
2. URL의 /d/ 뒤, /edit 앞의 스프레드시트 ID를 복사합니다.
3. Google Cloud Console에서 Google Sheets API를 사용 설정합니다.
4. 서비스 계정을 만들고 JSON 키를 발급받습니다.
5. JSON 파일의 client_email을 구글 시트에 편집자로 공유합니다.
6. 복지온 관리자 > 구글 시트 연동 화면에서 스프레드시트 ID와 JSON 파일을 설정합니다.
7. 연결 테스트 후 오늘 데이터 동기화를 실행합니다.

주의: 실제 service-account.json은 외부에 공유하지 마세요.
