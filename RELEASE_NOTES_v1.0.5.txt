복지온 WelfareON v1.0.5 릴리즈 노트

주요 변경 사항

1. 런처 중복 실행 방지
- Windows Mutex 방식으로 런처 단일 실행 잠금을 추가했습니다.
- 이미 런처가 실행 중인 상태에서 EXE를 다시 실행하면 새 창을 띄우지 않습니다.
- 중복 실행 시 “이미 복지온 런처가 실행 중입니다. 기존 창에서 작업을 계속 진행해주세요.” 안내창을 표시하고 종료합니다.
- WebView 내부 창 실행 모드는 예외 처리하여 프로그램 실행 창은 정상적으로 열리도록 했습니다.

2. 서버 중복 실행 처리 유지
- 기존 복지온 서버가 이미 실행 중이면 새 서버를 추가로 띄우지 않고 기존 서버에 연결하는 흐름을 유지했습니다.

적용 방법
1. 이 ZIP을 기존 WelfareON 배포 폴더에 덮어씁니다.
2. build_launcher.bat을 다시 실행합니다.
3. dist/복지온_Launcher.exe를 실행해 중복 실행 방지 동작을 확인합니다.
