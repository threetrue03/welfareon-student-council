# WelfareON v1.0.13 릴리즈 노트

## exe WebView 실행 안정화
- `dist` 폴더에서 빌드된 exe를 직접 실행해도 프로젝트 루트를 부모 폴더로 올바르게 인식하도록 수정했습니다.
- PyInstaller 빌드 옵션에 `webview`, `pythonnet`, `clr_loader` 수집을 강화했습니다.
- exe 모드에서 WebView 모듈이 누락된 경우 `pip install`을 시도하지 않고 재빌드 안내 오류를 남기도록 수정했습니다.
- WebView 실행 직후 종료 감시 시간을 5초로 늘려 exe 환경에서 내부 창 실행 실패를 더 정확하게 감지합니다.

## 구글 시트 연동 UX 정리
- `연결 테스트`와 `오늘 데이터 동기화` 실행 시 버튼 내부 로딩 애니메이션만 표시합니다.
- 화면 하단에 중복으로 표시되던 로딩 상태 박스를 삭제했습니다.
- 처리 중 버튼 비활성화와 중복 요청 방지 로직은 유지했습니다.
