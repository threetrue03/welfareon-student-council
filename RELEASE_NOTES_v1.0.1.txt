WelfareON v1.0.1 Release Notes

주요 업데이트
- 런처 초기 설정의 관리자 학번 입력을 숫자만 허용하도록 수정
- 런처 진행 로그 영역을 읽기 전용으로 변경
- 프로그램 환경 설정 단계의 세부 진행 상태와 로그 보기 버튼 추가
- 환경 설정 완료 후 자동 이동하지 않고 사용자가 다음 버튼을 눌러 이동하도록 수정
- 런처 종료 시 확인 경고창 표시
- 단체명 표현을 학과(부) 명으로 변경하고, 프로그램에는 <학과(부)명> 학생회 형식으로 표시
- 로그인 중 / 근무 종료 중 로딩 표시 추가
- 사용자 메뉴에 비밀번호 변경 기능 추가
- 근무 종료 버튼 이모티콘 제거
- 구글 시트 연동을 건너뛰면 테스트 ID/JSON 경로/관련 파일이 남지 않도록 수정
- 배포본 초기 학생 더미 데이터 제거
- 배포본 버전 및 업데이트 기록 문서 추가

배포 메모
- 프로그램 DB는 배포본에 포함하지 않습니다.
- 실제 admin.csv, service-account.json, 개인정보 xlsx는 포함하지 않습니다.
- Windows EXE는 Windows 환경에서 build_launcher.bat 실행 후 생성합니다.
