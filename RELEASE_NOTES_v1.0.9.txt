복지온 WelfareON v1.0.9 릴리즈 노트

런처 환경 설정 화면
- 하단 버튼/푸터가 작업 출력 영역에 밀려 잘리는 문제를 수정했습니다.
- 작업 출력 영역과 하단 액션 영역을 분리했습니다.
- 진행률이 항상 퍼센트 형식으로 보이도록 수정했습니다.

출력/인코딩
- Python subprocess 실행 환경에 UTF-8 설정을 적용했습니다.
- 한글 로그가 깨지는 문제를 완화했습니다.
- 사용자 화면에는 요약 로그를 표시하고 상세 원문 로그는 로그 파일에 저장하도록 정리했습니다.

로그인 UX
- 로그인 화면의 하단 로딩 박스를 삭제했습니다.
- 로그인 버튼 내부의 `로그인 중...` 문구만 유지했습니다.

빌드
- build_launcher.bat의 PowerShell 의존을 제거했습니다.
- build_launcher.py에서 콘솔 출력과 logs/build_launcher.log 저장을 함께 처리합니다.

서버 안정성
- /health/ 확인 API를 추가했습니다.
- 포트 충돌과 서버 시작 실패 처리를 강화했습니다.
- 서버 시작 실패 시 프로세스를 정리합니다.

보안/배포
- 관리자 비밀번호를 명령어 인자로 전달하지 않도록 변경했습니다.
- 배포 ZIP에서 캐시, 로그, 임시 DB, 빌드 산출물을 제외했습니다.

통계
- v1.0.7에서 삭제한 통계 탭 삭제 상태를 유지했습니다.
