복지온 WelfareON v1.0.18
배포일: 2026-08-03

주요 변경 사항
- 물품 기록에 소모품 지급 기록과 통계 화면을 추가했습니다.
- 통계에서 요일/시간대별 대여·반납, 비품 대여, 소모품 지급 수량, 연체 순위를 확인할 수 있습니다.
- 상반기·하반기 겨울방학 구분과 직접 날짜 선택을 추가했습니다.
- 구글 시트에 현재 대여 중인 항목을 보여주는 대여 현황 탭을 추가했습니다.
- 관리자 메뉴에서 관리자 학번을 추가·수정·삭제할 수 있습니다.
- 런처가 프로그램 시작 시 필요한 DB 마이그레이션을 자동 적용하고 완료 알림을 표시합니다.

업데이트 방법
1. 프로그램과 기존 서버를 모두 종료합니다.
2. v1.0.18 프로그램 파일과 새로 빌드한 복지온_Launcher.exe를 배포 폴더에 반영합니다.
3. 복지온_Launcher.exe를 실행하고 프로그램 시작 버튼을 누릅니다.
4. 필요한 DB 업데이트는 자동 적용됩니다.

주의 사항
- exe만 교체하면 웹 기능 변경이 반영되지 않습니다. app 폴더의 변경 파일도 함께 배포해야 합니다.
- 실제 DB, 관리자 CSV, 구글 서비스 계정 JSON은 Git 저장소와 배포본에 포함하지 않습니다.
