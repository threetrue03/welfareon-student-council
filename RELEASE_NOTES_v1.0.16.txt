WelfareON Distribution v1.0.16

변경 사항
- 런처 종료 확인창 문구를 “런처를 종료하시겠습니까?”만 보이도록 정리했습니다.
- WebView PID 파일이 꼬여도 --webview 프로세스를 탐색해 종료하도록 보강했습니다.
- 프로그램 종료 시 WebView 프로세스 트리와 서버 포트 점유 PID 정리를 강화했습니다.
- 수동 DB 전체 백업 화면을 추가했습니다.
- 학생/물품/근무자 DB 가져오기 전 자동 백업 ZIP을 생성하도록 추가했습니다.
- 근무자 DB 가져오기 시 현재 로그인 관리자가 비활성화/권한 해제되지 않도록 차단했습니다.
- 근무자 DB 가져오기 시 현재 로그인 관리자 비밀번호를 덮어쓰지 않아 세션 로그아웃과 접속 불가를 방지했습니다.
- 관리자 0명 상태 저장을 차단했습니다.
- 근무자 삭제를 실제 삭제가 아닌 비활성화 처리로 변경해 기존 대여/반납/근무 기록을 보존합니다.
- 학생 DB 가져오기에서 학생회비 납부 여부(납부/미납/환불)를 반영하도록 수정했습니다.
- 기록과 연결된 물품 삭제를 차단해 DB 보호 오류를 방지했습니다.
- 물품이 연결된 카테고리 삭제를 차단했습니다.
- Python 3.12.x를 우선 사용하도록 런처/빌드 스크립트를 고정했습니다.
- 배포본 정리를 위해 실제 서비스 계정 JSON 제거용 cleanup 스크립트를 포함했습니다.
