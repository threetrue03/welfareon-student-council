# WelfareON v1.0.3 Release Notes

## 런처 안정화
- 프로그램 환경 설정 단계에 진행 프로그레스바를 추가했습니다.
- 환경 설정 완료 후 같은 화면에서 `다음` 버튼이 활성화되도록 변경했습니다.
- 최초 설정 시 기존 테스트 DB가 남아 있으면 삭제하고 깨끗한 DB로 시작하도록 수정했습니다.
- 서버 중복 실행을 감지해 새 서버를 중복으로 띄우지 않고 기존 서버에 연결하도록 수정했습니다.
- 서버 PID 파일을 관리해 프로그램 종료 시 실행 중인 서버를 정리하도록 보강했습니다.
- build_launcher.bat 실행 실패 시 바로 꺼지지 않고 logs/build_launcher.log에 기록을 남기도록 수정했습니다.
- 콘솔창 노출을 줄이기 위해 서버/WebView subprocess 실행 방식을 보강했습니다.

## WebView/URL 처리
- WebView 내부에서 Shift+Enter, 새 창 열기, 외부 URL 이탈을 차단하도록 보강했습니다.
- 링크/폼의 target 속성을 자동 제거해 외부 창으로 빠지는 현상을 방지했습니다.

## 로그인/UX
- 로그인 로딩 표시가 초기 화면에서 미리 보이는 문제를 수정했습니다.
- 로그인 버튼 클릭 후에만 로딩 상태가 표시되도록 변경했습니다.

## 단체명 표시
- 학과(부) 명 뒤에 `학생회`가 중복으로 붙는 문제를 수정했습니다.
- 첫 실행 시 입력한 학과(부) 명은 내부적으로 정규화되어 `<학과(부)명> 학생회` 형태로만 표시됩니다.

## 배포 정리
- 배포본의 캐시/임시 파일을 정리했습니다.
- 업데이트 기록과 버전 정보를 v1.0.3으로 갱신했습니다.
