복지온 WelfareON 배포본 v1.0.17

사용 방법
1. WelfareON_Distribution_v1.0.17.zip을 원하는 위치에 압축 해제합니다.
2. 처음 실행 시 build_launcher.bat을 실행해 런처 exe를 생성합니다.
3. dist 폴더의 복지온_Launcher.exe를 실행합니다.
4. 첫 실행에서는 학과(부) 명과 최초 관리자 계정을 설정합니다.
5. 구글 시트 연동은 선택 사항입니다. 필요하지 않으면 건너뛰면 됩니다.

주의 사항
- Python 3.12.x 기준으로 빌드합니다.
- build_launcher.bat은 py -3.12로 빌드합니다. Python 3.12가 없으면 설치 후 다시 실행해주세요.
- 실제 DB, 실제 관리자 CSV, 실제 구글 서비스 계정 JSON은 배포본에 포함하지 않습니다.
- 오류 발생 시 logs/log.txt, logs/webview.log 또는 logs/build_launcher.log를 확인해주세요.

v1.0.17 주요 변경 사항
- 런처 종료 확인창 문구를 간단하게 정리했습니다.
- 프로그램 종료 시 WebView 잔여 프로세스 정리를 강화했습니다.
- 수동 DB 전체 백업 화면을 추가했습니다.
- 학생/물품/근무자 DB 가져오기 전 자동 백업을 생성하도록 추가했습니다.
- 근무자 DB 가져오기 시 현재 로그인 관리자 보호 로직을 추가했습니다.
- 현재 관리자 비밀번호가 XLSX 값으로 덮어써져 로그아웃/접속 불가가 발생하는 문제를 방지했습니다.
- 관리자 0명 상태 저장을 차단했습니다.
- 근무자 삭제를 실제 삭제 대신 비활성화 처리로 변경했습니다.
- 학생 DB 가져오기에서 학생회비 납부 여부를 반영하도록 수정했습니다.
- 기록과 연결된 물품/카테고리 삭제를 차단했습니다.
- Python 3.12.x 우선 사용 기준으로 빌드 스크립트를 수정했습니다.
- 배포본에서 실제 서비스 계정 JSON과 런타임 파일을 제거했습니다.
