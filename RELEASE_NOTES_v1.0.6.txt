복지온 WelfareON v1.0.6 릴리즈 노트

배포일: 2026-05-14

1. 런처 환경 설정 화면 개선
- 작업 출력 영역 높이를 확대했습니다.
- 작업 출력 영역에 세로 스크롤바를 추가했습니다.
- 로그가 추가될 때 최신 출력이 자동으로 보이도록 유지했습니다.
- 하단 버튼과 푸터가 작업 출력 영역을 침범하지 않도록 창 높이와 레이아웃을 조정했습니다.
- 세부 작업 문구가 어색하게 끊기지 않도록 줄바꿈 폭과 영역 높이를 조정했습니다.

2. 빌드 파일 정리
- build_launcher.bat 실행 시 콘솔에 빌드 로그가 표시되도록 개선했습니다.
- logs/build_launcher.log에도 빌드 로그를 저장합니다.
- 혼동을 줄 수 있는 build_bauncher.bat 오타 대응 파일을 제거했습니다.

3. 기존 기능 유지
- v1.0.5의 런처 중복 실행 방지 기능을 유지했습니다.
- v1.0.4의 통계 탭, D-day 표시, 반납 근무자 표시 수정 사항을 유지했습니다.
