WelfareON Distribution v1.0.15

변경 사항
- 물품/학생/근무자 DB 가져오기 업로드 버튼에 처리 중 로딩 스피너를 추가했습니다.
- 업로드 중 버튼을 비활성화해 중복 클릭과 중복 제출을 방지했습니다.
- 학생 DB/근무자 DB 가져오기 화면에서도 확인 모달과 업로드 로딩 처리가 안정적으로 동작하도록 스크립트 로드를 보강했습니다.
- SQLite 연결 timeout을 늘려 일시적인 DB 잠금 상황에서 바로 실패하지 않도록 완화했습니다.
- 물품/학생/근무자 DB 가져오기 저장 작업을 명시적인 트랜잭션으로 감싸고, DB 잠금 발생 시 500 오류 대신 안내 메시지를 표시하도록 수정했습니다.
- 근무자 DB 가져오기 중 database is locked 오류가 발생하던 상황을 완화했습니다.
- 배포본에서 실제 구글 서비스 계정 JSON과 테스트 xlsx 파일을 제외했습니다.
