복지온 WelfareON v1.0.4 릴리즈 노트

배포일: 2026-05-14

1. 런처/빌드 안정화
- build_launcher.bat 줄바꿈을 Windows CRLF 기준으로 정리했습니다.
- 경로에 공백이 있어도 안전하게 실행되도록 pushd와 따옴표 처리 방식을 보강했습니다.
- build_bauncher.bat 오타 실행을 대비한 호환 실행 파일을 추가했습니다.

2. 프로그램 환경 설정 UX 개선
- 환경 설정 화면의 왼쪽 진행 단계 박스를 제거했습니다.
- 현재 작업, 세부 작업, 진행률, 작업 출력을 한 화면에서 크게 확인할 수 있도록 변경했습니다.
- 프로그레스바를 실제 퍼센트가 올라가는 방식으로 변경했습니다.
- venv 생성, 패키지 설치, migration, 관리자 계정 생성 출력이 작업 출력 영역에 표시되도록 개선했습니다.

3. 조회 화면 개선
- 아직 반납되지 않은 대여 기록의 반납 근무자가 `삭제됨`으로 표시되던 문제를 수정했습니다.
- 미반납 상태의 반납 근무자는 `-`로 표시합니다.
- 학생으로 조회/물품으로 조회의 반납 예정일에 D-day 표기를 추가했습니다.

4. 통계 탭 추가
- 관리자 전용 통계 탭을 추가했습니다.
- 오늘 대여, 오늘 반납, 현재 대여 중, 현재 연체, 고장 물품, 분실 물품을 요약 카드로 확인할 수 있습니다.
- 기간별 일별 대여/반납 현황을 확인할 수 있습니다.
- 많이 대여된 물품 TOP 10, 카테고리별 대여 현황, 현재 미반납/연체 목록, 근무자별 처리 요약을 추가했습니다.
