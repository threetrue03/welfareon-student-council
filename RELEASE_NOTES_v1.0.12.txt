복지온 WelfareON v1.0.12 릴리즈 노트

변경 사항
- 구글 시트 연동 화면의 `연결 테스트` 버튼 클릭 시 로딩 애니메이션을 표시하도록 개선했습니다.
- 구글 시트 연동 화면의 `오늘 데이터 동기화` 버튼 클릭 시 로딩 애니메이션을 표시하도록 개선했습니다.
- 처리 중에는 버튼을 비활성화해 중복 클릭과 중복 요청을 방지합니다.
- 처리 중 현재 수행 중인 작업 문구를 별도 상태 박스로 표시합니다.
- 설정 저장 버튼은 기존처럼 즉시 저장 흐름을 유지합니다.

유지 사항
- v1.0.11의 WebView 중복 실행 방지, 프로그램 종료 처리, 구글 시트 설정 반영 구조를 유지합니다.
- 통계 탭 삭제 상태와 로그인 하단 로딩 박스 삭제 상태를 유지합니다.
