# WelfareON Distribution v1.0.10

## 런처 환경 설정 화면
- 환경 설정 화면을 고정 좌표 배치에서 유연한 grid/pack 기반 레이아웃으로 재구성했습니다.
- 작업 출력, 하단 버튼, 푸터 영역이 서로 겹치거나 잘리지 않도록 분리했습니다.
- 진행률 표기를 `진행률 n%` 형식으로 고정했습니다.

## 프로그램 시작 UX
- 프로그램 시작 버튼 클릭 후 `시작 중...` 상태를 표시하고 중복 클릭을 방지합니다.
- 서버 상태 확인, 서버 시작, 내부 창 실행 단계를 상태 문구로 보여줍니다.
- 서버가 이미 실행 중이면 새 서버를 띄우지 않고 내부 창 연결만 시도합니다.

## 내부 창 실행 안정성
- WebView 실행 로그를 `logs/webview.log`에 저장합니다.
- WebView 프로세스가 실행 직후 종료되면 실패로 감지합니다.
- 내부 창 실행 실패 시 기본 브라우저로 열 수 있는 대체 경로를 제공합니다.
- 대시보드에 `브라우저로 열기` 버튼을 추가했습니다.

## 빌드/배포
- PyInstaller 빌드 시 pywebview 관련 하위 모듈 포함 옵션을 보강했습니다.
- 배포본에서 캐시, 로그, 빌드 산출물, 임시 DB는 제외합니다.

## 유지 사항
- v1.0.9의 로그인 하단 로딩 박스 삭제 상태를 유지합니다.
- 통계 탭 삭제 상태를 유지합니다.
