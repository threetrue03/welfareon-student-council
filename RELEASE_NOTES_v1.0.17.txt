복지온 WelfareON v1.0.17 릴리즈 노트

1. 모든 DB 변경성 POST 작업 버튼에 버튼 내부 로딩 애니메이션을 추가했습니다.
2. 물품 대여 화면의 학생 전화번호 저장/다음 단계 버튼에 로딩 상태를 추가했습니다.
3. 물품 대여 처리, 물품 반납 처리 버튼에 중복 제출 방지와 처리 중 표시를 추가했습니다.
4. 물품/카테고리/학생/근무자 추가·수정·삭제 및 설정 저장 버튼에 공통 로딩 처리를 적용했습니다.
5. DB 가져오기와 DB 전체 백업 버튼의 로딩 상태를 유지하면서 공통 처리 흐름과 맞췄습니다.
6. 사용자 미니창에 어두움 모드 토글을 추가했습니다.
7. 어두움 모드는 완전 검정이 아닌 눈부심을 줄인 다크 그레이 팔레트로 구현했습니다.
8. 테이블, 카드, 모달, 입력창, 토스트, 달력, 사이드바 하단 사용자 메뉴의 다크 모드 깨짐을 보정했습니다.
9. 선택한 화면 모드는 localStorage에 저장되어 다음 실행 때도 유지됩니다.
10. 물품 대여/반납 JS의 중복 변수 선언 오류를 정리했습니다.
