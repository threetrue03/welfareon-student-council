근무자 DB 가져오기

근무자 DB를 새 파일 기준으로 반영합니다.
  • 파일에 없는 기존 근무자는 로그인할 수 없게 처리됩니다.
  • 관리자 계정은 최소 1명 이상 있어야 합니다.
  • 관리자 여부에 따라 auth/admin.csv가 자동 수정됩니다.
  • 현재 로그인 중인 관리자는 파일에 포함되어 있어야 하며 관리자 권한이 유지되어야 합니다.
  • 현재 로그인 중인 관리자 비밀번호는 세션 보호를 위해 덮어쓰지 않습니다.
  • 가져오기 전 자동 백업 ZIP이 생성됩니다.
