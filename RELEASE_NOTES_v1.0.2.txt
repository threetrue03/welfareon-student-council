WelfareON v1.0.2 Release Notes

주요 업데이트
- 런처 종료 확인창에서 확인을 누르면 런처와 실행 중인 프로그램이 확실히 종료되도록 수정
- 물품 관리에 물품 위치 입력/수정/저장 기능 추가
- 물품 DB 가져오기 양식을 물품명 | 물품 위치 | 카테고리 | 물품 특성 | 전체 수량 | 현재수량 구조로 변경
- 물품 관리 표를 물품명 | 물품 위치 | 유형 | 카테고리 | 수량/상태 | 관리 구조로 변경
- 물품 대여/지급 화면에서 물품 번호 선택 위에 물품 위치 표시
- 물품 반납 화면에서 반납 물품 번호 선택 위에 물품 위치 표시
- 물품 검색에서 물품 위치도 함께 검색되도록 보정
- 사이드바 접힘 상태에서 사용자 아이콘이 표시되지 않도록 수정
- 구글 시트 재고 현황에 물품 위치 열 추가
- 물품 위치 DB 마이그레이션 추가

배포 메모
- 기존 DB를 사용하는 경우 앱 실행 시 마이그레이션으로 물품 위치 필드가 추가됩니다.
- 배포본에는 실제 DB, 실제 관리자 CSV, 실제 구글 서비스 계정 JSON이 포함되지 않습니다.
